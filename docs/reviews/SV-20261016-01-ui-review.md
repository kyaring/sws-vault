# SV-20261016-01 UI 验收报告（Hark，apple-design）

被审提交：d7ed29c（feat/ui-v1），对照 docs/design/ui/UI-SPEC.md 和 mockups 检查。
取证方法：在临时 worktree 里加了一个只用于导出页面的测试（不提交），用 httptest 渲染 16 个页面并造了 3 个密钥、2 个项目；导出的 HTML 加上分支里的 admin.css/admin.js，在 390×844@2x 下截图（浅色全部页面，深色只截首页）。没有碰 9531。

## 结论：CHANGES REQUESTED（UI）— 3 High、5 Medium、3 Low
整体骨架已经到位：外壳、大标题、分组列表、吸底主按钮、深色模式、CSP 都合规，对比度沿用规范里的令牌，没有问题。但有几处明显偏离设计稿，手机上能直接看出来。

## High
1. **「退出」被渲染成全宽主按钮**（修改初始密码页、高级页）。原因是 `form > button:last-of-type { width:100% }` 加上退出表单。修改初始密码页上，它夹在输入框和「修改密码」之间，很容易误点。修法：退出统一只放在顶栏右侧，做成文字链接或 `.btn.plain`；页面主体里不出现退出按钮；修改初始密码和绑定 TOTP 这类流程页的顶栏也不放退出。
2. **手机上表格表头没有隐藏**（客户端、审计）。表格没有 `<thead>`，`thead{display:none}` 不起作用，表头被堆成一列「ID / 项目 / 名称…」。修法：表头放进 `<thead>`、数据放进 `<tbody>`，每个 td 带 `data-label`（现在已有），并补一条测试断言 `<thead>`。
3. **首页主操作卡被另一条规则污染，图标也缺失**：新加的 `nav a, a.primary {justify-content:center…}` 命中了 `.action.primary`，导致「新建」卡的内容居中，和右边那张卡不一致；图标用的是「＋」「↗」文本字符，品牌锁图标和行图标 `.dot` 都没有。卡片文字写成了「新建密钥 / 保存一项凭据」，与 OPC 12:59 定的「新建」不符。修法：把 `a.primary` 改成不会冲突的类名（例如 `.nav-pill`）；按 mockups/03-home.html 用内联 SVG 实现锁、加号、链接、收件箱、盒子、钥匙、时钟、齿轮八个图标（可以抽成模板函数）；文案按效果稿：「新建 / 存一个密钥」「接入项目 / 生成令牌和配置」。

## Medium
4. **admin.css 末尾追加了一段「Shared layout additions」**，重复覆盖了 label、input、button、dl、.secret、legend 等正本规则（圆角从 10 变成 12，dl 的内边距变成 `12px 0`，导致「已保存」页的 dt/dd 贴边，.secret 的阴影变成描边），而且交付说明里没有列改动清单。修法：删掉重复覆盖的部分，只保留确实缺的规则（`.gitea-only`、`:has()`、`.inline-form`、`details`、`.copy-fallback`、`.stats`），并在交付说明里逐条列出。
5. **高级页还是带圆点的下划线链接列表**。修法：改成 `.group` + `a.row`，每行配图标，与首页「更多」组一致。
6. **新建页缺少说明文字和提示**：没有 `.lead`（「粘贴后立即加密保存…」），关联项目下面没有「不关联时，任何客户端都无法调用」，Gitea 地址下面没有「只会发往这个域名」；平台卡片没有品牌色块（CF/GH/Gt/··），「Cloudflare API Token」折成两行。修法：按 mockups/04-new.html 改，卡片文字统一写平台名 Cloudflare / GitHub / Gitea / 通用。
7. **项目配置页的层级反了**：「PUBLIC_BASE_URL 未配置」是普通段落，应改为 `.note.warn`；一大段「使用范围」说明放在配置块前面，用的是正文字号，应移到底部，用 `.hint`；三个「复制」按钮都是实心主色，违反「每页只有一个主按钮」，应改为 `.btn.small.secondary`。
8. **错误页文案是英文**（`not found`）。卡上写的是「文案不变」，所以这条不算违约，但面板错误页应该给中文。修法：只在面板错误页的渲染层，把常见的 400/403/404 映射成中文（「找不到这个页面」等），/v1 的 JSON 不变。

## Low
9. 首页项目行同时有「查看」和箭头，「查看」多余，去掉；未关联行补上副标题「还没给任何项目，暂不可调用」。
10. 接入项目第 2 步的「返回上一步 · 取消」改成顶栏「‹ 上一步」，与效果稿一致。
11. 客户端页的「创建客户端」放在吸底栏里，会盖住下面的表格。高级子页的主按钮改成随表单放在原位（`.btn.block`），不吸底；吸底只用于快速流程页。

## 合规项（保持）
CSP 头不变；全页面没有内联样式、脚本或事件属性（GPT 的测试已覆盖）；viewport 和 admin.css 都在；深色模式自动切换；输入框字号 16px；触控高度不低于 44px；复制功能用外链 admin.js，没有 JS 时页面仍可用。
