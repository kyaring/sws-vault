## 必改（全部做完才能交付）
1. **[阻塞，问题 1] version 输出 commit**：在 worktree 和 -trimpath 下，当前构建拿不到 vcs 信息，输出的是 `dev`。改法：
   - 在 Makefile 里新增 `build` 目标，用 `-ldflags "-X main.commit=$(git rev-parse --short=12 HEAD)"` 注入 commit；ReadBuildInfo 只作为兜底；
   - 加一个测试，验证注入的值会被 version 子命令输出；
   - README 和 docs/ops.md 里的构建命令统一改用 `make build`（或者把完整的 ldflags 写明）。
   - 验收：`make build && ./bin/swsvault version` 输出的值必须等于 `git rev-parse --short=12 HEAD`。
2. **[问题 2] resolve 的 allow_resolve 门禁**：补测试。有 resolve scope 但 bindings 里没开 allow_resolve 时，必须拒绝（返回 403，或者按现有约定返回码），并且不返回值。
3. **[问题 3] resolve 的 Cache-Control: no-store**：补测试，断言 resolve 的响应头里有 no-store。
4. **[问题 4] 主密钥权限**：补测试。master.key 权限为 0644 或 0640 时，serve 和加载主密钥都必须拒绝；0600 时放行。
5. **[问题 6] SSRF 边界情形回归测试**：URL 带 userinfo、主机名大小写不同、末尾带点、IPv6 字面量（[::1] 和 [fd00::1]）、十进制 IP（2130706433）、169.254.169.254，每种都要有测试用例，验证结果符合现在的行为（拒绝，或者经规范化后再精确匹配）；另外丢弃调用方 X-Auth-* 和 Cookie 的行为也要有断言。
6. **[问题 7] 面板 cookie**：补测试，断言 HttpOnly、SameSite=Strict，并且 public_base_url 为 https 时设置 Secure；再测一下 8 小时绝对超时（可以注入时钟）。
7. **[问题 8，升级为必改] 关闭 /admin/assets/ 的目录列表**：请求目录时返回 404，只允许精确的文件路径；补测试。
8. **[问题 12，升级为必改] 登录锁定不能被任何人随手触发**：现在的全局锁定，谁都能用 5 次失败把管理员锁住。改成按来源 IP 锁定（连续 5 次失败锁 15 分钟），全局只做退避，不做硬锁。来源 IP 只在请求来自配置里的可信代理时才读 X-Forwarded-For。补测试：IP A 被锁时，IP B 仍能正常登录。
9. **[问题 12] 内存表清理**：sessions 和 rateState 定期清理过期项（例如惰性清理，或者每分钟清一次）；补测试。
10. **[问题 12] 改绑定校验**：admin_extra.go 改绑定时复用 validation.go 里的主机格式校验，非法主机返回 400；补测试。
11. **[问题 12] 删掉** generate.go 里的空循环死代码。
12. **[问题 9] 用户名打码**：list、面板、MCP 返回的 bindings 里不再出现 username 原文，统一显示 preview 里的打码形式；注入时照常使用原文。哨兵测试增加一项：用户名哨兵也不能出现在 list 和面板里。
13. **[问题 5] client 令牌比较**：按哈希取到行之后，再用 subtle.ConstantTimeCompare 复核一次哈希，与卡面「常数时间比较」的要求保持一致。
