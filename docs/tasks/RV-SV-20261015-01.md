## 二、安全逐条核对（重点，每条都要写「通过 / 不通过 / 证据位置（文件:行号或测试名）」）
1. **只写不读**：用 grep 找出所有路由注册，列出完整路由表。除 `POST /v1/resolve` 外，任何接口和面板页面都不能返回明文。resolve 必须同时满足三条：有 resolve scope、secret 的 bindings 开启了 allow_resolve、响应头带 Cache-Control: no-store；并且每次调用都写审计。
2. **加密**：每条 secret 使用独立 DEK，AES-256-GCM，nonce 随机且不复用；AAD 包含 ns、id、type 和 key_version；KEK 由 HKDF 从主密钥派生；fingerprint 是 HMAC，不是普通哈希；数据库中没有明文，也没有明文的普通哈希。
3. **主密钥**：keygen 不覆盖已有文件，生成的文件权限为 0600，任何输出都不含密钥；serve 在主密钥文件权限宽于 0600 时拒绝启动。核对代码和测试。
4. **client 令牌**：用 crypto/rand 生成，只存 SHA-256 哈希，比较时用常数时间比较；停用和过期都生效；CIDR 白名单起作用；限流返回 429。
5. **fetch / SSRF**（逐项核对代码）：只允许 https，除非 allow_http；主机精确匹配白名单；拒绝 loopback、私网、link-local、169.254.169.254 和 IPv6 的对应地址；**拨号时使用已校验的固定 IP**（检查自定义 DialContext，确认不会二次解析）；不跟随重定向；丢弃调用方的 Authorization、X-Auth-*、Cookie；有超时和 1 MB 上限；脱敏覆盖原文、base64、URL 编码三种形式，响应头和响应体都要覆盖。另外检查：URL 里带 userinfo（`https://a@evil/`）、主机名大小写不同、末尾带点（`api.github.com.`）、IPv6 字面量、十进制 IP 这些情况的处理。
6. **面板**：argon2id 参数合理；TOTP 拒绝重放；连续失败会锁定；cookie 设置了 HttpOnly 和 SameSite=Strict，并按条件设置 Secure；空闲 15 分钟、最长 8 小时会过期；所有表单都有 CSRF 校验；CSP、X-Frame-Options、Referrer-Policy 齐全；模板里没有 template.HTML 绕过转义；密码框不回显。
7. **intent**：只能用一次（检查并发下是否也只能用一次）、10 分钟过期、令牌只存哈希、录入页不泄露其他信息。
8. **日志和审计**：grep 所有 log.、fmt.Print、slog 的调用，确认没有记录值、请求头或请求体；审计表的字段里没有值。
9. **CLI**：run 只把值注入子进程的环境变量，不写盘，输出脱敏，退出码透传；capture 只从 stdin 读值；env-file 权限宽于 0600 时拒绝；git-credential 只在 get 时返回值，store 和 erase 不做任何事。
10. **MCP**：工具权限与 REST 一致，走同一个 service 层；没有 MCP 独有的、能拿到明文的路径。
