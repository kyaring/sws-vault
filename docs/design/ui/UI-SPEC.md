# SWS Vault 管理面板 UI 规范 v1

作者：Hark　日期：2026-10-16　状态：OPC 01:30 定稿
依据：Apple HIG（适用于网页的部分：无障碍、颜色、字体、布局、文案）；本面板以安卓手机竖屏为主要使用场景，同时兼顾桌面。

## 0. 文件
- `admin.css`：**正本样式**。实施时整份替换 `web/admin.css`，只允许修 bug 和补缺，改动要在交付说明里逐条列出。
- `mockups/*.html`：8 屏效果稿（登录、绑定 TOTP、首页浅色、首页深色、新建、已保存、选密钥、项目配置）。用浏览器打开就能看，它们引用同目录下的 admin.css。效果稿里的 `style=""` 只是为了出图方便，**实施时一律改用 class**（原因见第 5 节 CSP）。

## 1. 设计令牌（全部定义在 admin.css 的 :root 里，禁止写死颜色）
| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| --bg | #F2F2F7 | #000000 | 页面底色 |
| --surface | #FFFFFF | #1C1C1E | 卡片、分组 |
| --text / --text-2 | #1C1C1E / #5B5B62 | #F2F2F7 / #A1A1A8 | 正文 / 次要文字（≥6.6:1） |
| --accent | #2F4FD9 | #8EA2FF | 主色（≥6.4:1） |
| --ok / --warn / --danger | #1E7A3C / #8A5300 / #C62828 | 见 css | 状态色，都要搭配文字使用，不能只靠颜色区分 |
- 字体：系统字体栈（PingFang SC / Noto Sans SC），等宽字体用于令牌、域名、命令。
- 字号：大标题 30/700；正文 16；次要文字 13–15；**输入框不小于 16px**，避免手机聚焦时页面被放大。
- 间距以 4 为基数（8、12、16、20、24），圆角卡片 14，控件圆角 10。
- 触控区域：所有可点元素不小于 44px，按钮 50px，列表行 52px。
- 深色模式：跟随 `prefers-color-scheme` 自动切换，不加切换按钮。

## 2. 页面结构（每页统一）
1. 顶栏 `.appbar`：左边是品牌名或「‹ 上级」，右边是次要操作（列表页是「设置」，项目详情是「编辑」）。
   表单页的顶栏只有「取消」+ 居中标题 `.page-title`。
2. 大标题 `h1`，下面一行 `.lead` 说明。
3. 内容：用分组 `h2` 加 `.group`（列表行用 `.row`），或者用表单。
4. 主操作放在吸底栏 `.bar`，每页**只有一个**主按钮；次要操作用 `.btn.secondary`。
   有标签栏时 `.bar` 自动上移一档（`body.has-tabbar .bar`）。
5. 页面宽度最大 560px，居中；桌面端放宽到 720px。

## 2.5 导航骨架（v2，SV-20261016-07）
1. **三个标签**：底部固定 `.tabbar`，三项「密钥」`/admin/secrets`、「项目」`/admin/projects`、「记录」`/admin/audit`；
   当前项带 `aria-current="page"`，每项触控区 ≥44px，底部留 `env(safe-area-inset-bottom)` 安全区。
2. **只有一个入口**：每个功能只出现在一个标签里；旧首页的磁贴和分组入口全部删除，登录后与 `/admin/` 都 303 到 `/admin/secrets`。
3. **设置**：列表页右上角「设置」→ `/admin/settings`（修改密码、两步验证、退出登录三行）。
4. **表单页不带标签栏**：新建 / 添加 / 编辑类页面（含「放入密钥」「编辑项目」「生成录入链接」「放进项目」）
   顶栏只有「取消」+ 标题，取消固定回上级页面，不看浏览器历史。
5. **详情页的上级**：密钥详情 →「‹ 密钥」，项目详情 →「‹ 项目」，接入方详情 →「‹ 项目名」，都用固定链接。
6. **术语**：面板上只许用「密钥」「项目」「接入方」三个词。
   全站管理页不得出现：命名空间、客户端、client（显示文字）、高级、意图、intent、接入项目、未关联、绑定。
   测试用固定字符串断言，只查用户可见文本，不查 URL 和 name 属性。
7. **旧地址**一律 303：`/admin/advanced`、`/admin/advanced/secrets` → `/admin/secrets`；`/admin/clients` → `/admin/projects`；
   `/admin/namespaces` → `/admin/projects`；`GET /admin/quick/project` → `/admin/secrets/new`（POST 处理保留）。

## 3. 各页要求
- **登录**：使用 `.auth` 居中布局，包含 logo、密码、验证码（`.otp`、`inputmode=numeric`、`autocomplete=one-time-code`），底部用 `.note.warn` 提示「明文 HTTP 只录测试密钥」（仅在非 https 时显示）。
- **改初始密码 / 绑定 TOTP**：顶栏写「首次设置 1/2、2/2」；用 `.steps` 列出步骤；二维码放在 `.qr` 白底容器里，深色模式下也保持白底；手动密钥默认折叠（用 `<details>`）。
- **密钥标签**：h1「密钥」+ `.lead`；右上角 `.page-action` 里的「＋」→ `/admin/secrets/new`；
  按项目分组，未归入项目组置顶（`未归入项目 · N`，N=0 不显示该组），每行 `.dot` 图标 + 名称 +「平台 · 尾号 xxxx · 接入方数 / 已停用 / 还没人能用」；
  密钥数 >20 才在顶部出现搜索框（GET `q`）。
- **密钥详情**：h1 + `.lead`（平台 · 尾号 · 指纹前 8 位）；「项目」「最近使用」两行；「谁在用」每行一个开关 + 保存；
  「请求限制」用 `<details>` 折叠，摘要右侧 `.summary-value` 显示第一个 host，展开就是使用范围表单；底部「轮换」「停用」。
- **新建密钥**：平台单选卡片 `.choices`/`.choice`（Cloudflare / GitHub / Gitea / 其他）；名称、密钥值（`type=password`，占位「粘贴到这里，保存后不再显示」）；
  Gitea 地址与「允许 HTTP」只在选中 Gitea 时显示，「其他」的域名与 Header 模板同理（纯 CSS `:has()`，不支持时全部显示仍可用）；
  「放进项目」用 `<select>`，第一项是「先放在『未归入项目』」。
- **已保存**：`.hero` 显示对勾，`.lead` 写「名称 · 平台 · 尾号 / 放在项目 X」；「给谁用 →」是主按钮，下面一行 hint 说明，再下面是「完成」（secondary）。
- **项目详情**：h1 + 简介；「密钥」组每行进密钥详情，最后一行「放入密钥」（`.row.accent`）→ `/admin/projects/{name}/secrets/add`；
  「接入方」组每行进接入方详情，副标题「权限 · 来源 IP · 状态」；底部「添加接入方」；顶栏右上角「编辑」。
- **接入方详情**：h1 +「备注 · 创建于 X」；状态行（`.badge` 正常 / 已停用 + 最近使用）；设置表单（备注、权限、来源 IP）；
  「能用哪些密钥」每行一个开关 + 保存；底部「重新生成通行证」「停用」。
- **添加接入方**：分节「谁来调用 / 能用哪些密钥 / 权限 / 来源 IP（可选）」；权限用两段式 `.choices`（仅代发（推荐）/ 可取明文）；
  密钥行默认不勾选，带 `?secret=` 时只预勾这些；吸底栏「生成通行证」。
- **通行证结果页（项目配置）**：顶部用 `.note.danger` 写「令牌只显示这一次」；每段配置放在 `.secret`（header 加复制按钮，内容用 pre）；底部用 hint 写本次关联数。
- **放入密钥 / 编辑项目 / 生成录入链接 / 放进项目 / 移出项目**：都是表单页外壳（顶栏「取消」+ 标题），内容用 `.group` 行或表单。
- **记录、设置**：套用同样的外壳（appbar、h1、group 或 table）。表格在手机上变为卡片，每个 `td` 要带 `data-label`。
  状态与动作都显示中文。危险操作（停用、移出）用 `.btn.danger`。
- **错误页**（errOut 400/403/404）：同样套外壳，用 `.note.danger` 显示文案，并提供返回链接，不要只输出一行纯文本。

## 4. 文案
- 界面上不出现 namespace、NS、client_id 这类内部词；只用「密钥」「项目」「接入方」三个词（禁用词表见 §2.5）。
- 按钮文字写动作：保存、完成绑定、生成项目配置，不写「提交」。
- 涉及安全的提示放在操作之前，不要放在之后。

## 5. 技术约束
- 服务器 CSP 是 `default-src 'self'`：**禁止内联 `<style>`、`style=""`、内联 `<script>`、`on*=`**。复制按钮等交互放到嵌入的 `web/admin.js`，与 admin.css 一样由 `/admin/assets/` 提供，并且要能渐进增强：没有 JS 时页面完全可用。
- 复制按钮在 JS 里读取相邻 `pre` 的文本，令牌不得出现在 `data-*` 属性、URL 或日志里。
- 不引入任何外部资源（字体、CDN、图标库），图标全部用内联 SVG。
- 每个页面都要有 `<meta name="viewport" content="width=device-width,initial-scale=1">` 和 admin.css。
